# Интерфейс ObsFit

Пользователь выбрал минималистичный интерфейс. При дальнейших изменениях:

- Экономьте вертикальное пространство: не выделяйте строку для действия, которое помещается в существующую панель.
- Сокращайте переходы и число нажатий; предпочитайте прямые действия.
- Второстепенные подробности помещайте в раскрывающиеся секции.
- Не добавляйте ненужные подписи, экраны и подтверждения.
- Для компактных кнопок с символом сохраняйте понятное описание для доступности и удобную область нажатия.
